Claude에 힉스필드 연결하는 방법 (2026년 10월 기준)

2026-10-12 · 소통마케팅센터
#Claude힉스필드연결#힉스필드커넥터#ClaudeMCP#AI영상제작#AI이미지생성#커스텀커넥터#힉스필드사용법#제천마케팅교육#소통마케팅센터#AI도구활용

Claude 대화창에서 "이 장면 영상으로 만들어줘" 한마디로 힉스필드 생성 기능을 바로 쓰는 방법이 있습니다. 커스텀 커넥터 하나만 추가하면 됩니다. API 키 발급 과정 없이 힉스필드 계정 로그인 승인만으로 연결이 끝나며, 생성할 때마다 요금제 크레딧이 차감되는 구조입니다.

이 글은 직접 연결해 보며 막혔던 지점까지 정리한 가이드입니다. Claude 설정 메뉴 명칭과 위치는 업데이트로 바뀔 수 있습니다.

힉스필드 커넥터, 연결 전 준비물은?

연결 전 아래 네 가지를 먼저 확인해야 합니다.

  1. 힉스필드 계정과 활성화된 유료 구독
  2. Claude 계정 (웹 또는 데스크톱 앱)
  3. 커스텀 커넥터 추가 권한 (팀·기업 플랜은 관리자 허용 필요할 수 있음)
  4. 로그인 팝업이 차단되지 않은 브라우저

구독이 없는 상태에서는 연결 자체는 되더라도 생성 기능이 정상 작동하지 않을 수 있으니 구독 상태부터 점검하시길 권합니다.

Claude에 힉스필드 연결하는 방법, 5단계면 충분

전체 과정은 길지 않습니다. 순서대로 따라 하시면 됩니다.

  1. 설정 → 커넥터 이동 (왼쪽 아래 프로필 클릭)
  2. 커스텀 커넥터 추가 클릭 (오른쪽 위 추가 버튼 안)
  3. 이름 Higgsfield 입력, 주소란에

https://mcp.higgsfield.ai/mcp 붙여넣기

  1. 인증 옵션은 기본값 유지 (로그인·Claude 게시 ID 자동 선택, 헤더는 비워둠)
  2. 힉스필드 승인 창에서

주소가 higgsfield.ai인지, 요청 주체가 Claude인지 확인 후 Allow 클릭 요청 권한은 신원 확인, 이메일 주소, 로그인 유지 세 가지입니다. 승인이 끝나면 커넥터 목록 Higgsfield 옆에 체크 표시가 나타납니다.

연결했는데 작동 안 할 때, 뭐가 문제일까?

가장 흔한 증상은 "사용 가능한 도구가 없습니다" 라는 문구입니다. 이는 연결 실패가 아니라 도구 목록이 아직 반영되지 않은 상태입니다.

  1. 로그인 승인(Allow)까지 끝났는지 재확인
  2. 새 대화에서 "힉스필드 커넥터로 쓸 수 있는 도구 목록 알려줘" 입력
  3. 그래도 비어 있으면 앱 완전 종료 후 재실행
  4. 마지막으로 커넥터 삭제 후 OAuth 클라이언트를 자동 등록으로 바꿔 재추가

연결 도중 확인 창이 여러 번 뜨는 경우도 있는데, 앱에서 직접 시작한 연결이라면 계속 연결을 누르면 됩니다. 다만 주소창이 higgsfield.ai가 맞는지는 매번 확인하는 습관이 필요합니다. 간혹 목록에 있던 다른 커넥터(예: Canva)의 다시 연결 창이 섞여 뜨기도 하는데, 힉스필드와는 무관하니 필요 없으면 닫으시면 됩니다.

첫 테스트는 어떻게 진행하나요?

연결 후 가장 먼저 도구가 보이는지 확인해야 합니다. 새 대화에서 "힉스필드 커넥터로 쓸 수 있는 도구 목록 알려줘" 라고 물어보시면 됩니다. 도구가 나오면 짧은 클립으로 첫 테스트를 진행하시길 권합니다. 생성할 때마다 크레딧이 차감되므로 5초 이내 길이로 시작하는 것이 안전합니다.

예: "힉스필드로 5초짜리 제천 의림지 풍경 영상 만들어줘" 형태로 요청하면 됩니다. API 키 없이도 되는지, 구독 없이 연결 가능한지, 연결 해제는 어떻게 하는지는 설정 → 커넥터 화면에서 Higgsfield 선택 후 연결 해제 버튼으로 간단히 처리할 수 있습니다.

같은 힉스필드 계정은 ChatGPT, Cursor 등 MCP 지원 도구에도 함께 연결해 쓸 수 있습니다.

정리하면 설정 → 커넥터 → 커스텀 커넥터 추가 → 주소 입력 → 로그인 승인, 이 다섯 단계로 Claude와 힉스필드 연결이 끝납니다. 이런 AI 도구 연결이나 영상 제작 자동화를 사장님이 직접 다루실 수 있도록 돕는 일을 소통마케팅센터에서 하고 있습니다. 제천, 단양, 영월, 원주 지역 사장님들께 1:1로 설명드리며 함께 세팅해 드리니, AI 도구 도입이 막막하시다면 편하게 문의 주셔도 좋습니다.
