인스타 댓글 자동 DM 설정 방법 - 메타 앱 6단계와 막히는 함정 3가지 (2026년 새 화면)

2026-11-25 · 소통마케팅센터
#인스타자동DM#인스타댓글자동DM#인스타그램DM자동화#메타개발자#InstagramAPI#인스타웹훅#인스타마케팅#소상공인인스타#제천마케팅#소통마케팅센터

인스타 댓글에 자동으로 DM을 보내려면 메타 개발자 사이트에서 앱을 만들고, Instagram 테스터 등록, 광고 권한을 뺀 구성 만들기, 액세스 토큰·앱 시크릿 발급, 웹훅 등록과 comments 구독까지 6단계를 거치면 됩니다. 2026년 11월 소통마케팅센터 인스타 계정에 직접 연결하면서 실제로 된 순서를 기준으로 정리했습니다.

메타가 새로 만드는 앱에는 예전의 「Instagram 로그인을 통한 API 설정」을 없애고 통합 로그인(Unified login) 방식만 남겼습니다. 그래서 예전 안내 글대로 하면 중간에 메뉴가 없거나 토큰이 만들어지지 않습니다.

인스타 댓글 자동 DM은 어떤 원리로 보내지나요?

손님이 릴스에 정해 둔 낱말(예: 견본)로 댓글을 달면, 메타가 웹훅으로 서버에 알림을 보내고, 서버가 그 손님에게 링크 DM과 공개 답글을 보냅니다. 메타 화면에서 할 일은 앱 만들기, 계정 연결, 토큰 발급, 알림 주소 등록까지이고, DM 발송은 서버(또는 자동 DM 서비스)가 맡습니다.

시작 전에 무엇이 필요한가요?

  • 프로페셔널 계정(비즈니스·크리에이터)으로 바꾼 인스타 계정
  • 메타 비즈니스 포트폴리오 1개
  • 댓글 알림을 받아 DM을 보낼 서버 주소(직접 만든 서버 또는 자동 DM 서비스가 주는 주소)

메타 앱 설정 6단계 한눈에 보기

단계어디서할 일
1. 앱 만들기developers.facebook.com → 내 앱이용 사례 「Instagram에서 메시지 및 콘텐츠 관리」 선택, 비즈니스 포트폴리오 연결
2. 테스터 등록앱 역할 → 역할 → 사람 추가「Instagram 테스터」로 추가 → 인스타 웹 앱 및 웹사이트 → 테스터 초대 수락
3. 구성 만들기이용 사례 → 맞춤 설정 → API setup with Unified login새로운 구성 만들기 → 템플릿 → [수정]에서 광고 계정·ads 권한 빼기
4. 토큰 발급같은 화면 2. 액세스 토큰 생성토큰 생성 → 페이스북으로 계속 → 이해합니다 체크 → 복사
5. 앱 시크릿앱 설정 → 기본 설정앱 시크릿 코드 [보기] → 토큰과 함께 서버에 입력
6. 웹훅 등록같은 화면 3. Webhooks 구성콜백 URL·인증 토큰 입력 → 확인 및 저장 → comments 구독 켜기

가장 많이 막히는 함정 3가지는 무엇인가요?

① 이용 사례 목록에 인스타가 없다

앱 만들기 두 번째 화면은 '추천' 필터가 기본이라 인스타 항목이 보이지 않습니다. 왼쪽 [콘텐츠 관리] 필터를 눌러야 나옵니다.

② 그냥 '테스터'로 추가했다

역할 목록 위쪽의 '테스터'는 페이스북용입니다. 맨 아래 「Instagram 테스터」로 추가하고, PC 인스타그램 웹의 앱 및 웹사이트 → 테스터 초대 탭에서 수락해야 토큰 표에 계정이 나타납니다.

③ 구성에 광고 권한을 남겼다

템플릿으로 만든 구성에는 ads_management · ads_read 권한과 광고 계정이 들어 있습니다. 이것을 빼지 않으면 토큰을 만들 때 광고 계정 칸에 「새 광고 계정 만들기」만 나와 진행이 막힙니다. 구성 [수정]에서 두 권한과 광고 계정을 빼면 해결됩니다.

액세스 토큰은 어떻게 보관해야 하나요?

토큰 생성됨 창은 토큰을 한 번만 보여 줍니다. [이해합니다]에 체크하고 바로 복사해 저장하세요. 통합 로그인 방식에서 나오는 토큰은 EAA로 시작하는 시스템 사용자 토큰으로 만료가 없기 때문에, 유출되면 누구나 계정을 대신 움직일 수 있습니다. 메신저나 캡처로 공유하지 말고 서버 설정에만 넣으세요.

웹훅을 저장했는데 댓글 알림이 오지 않아요

콜백 URL과 인증 토큰을 저장한 뒤 아래 필드 목록에서 comments 의 [구독]을 켜야 합니다. 기본값이 꺼져 있습니다. 또 「먼저 1단계에서 구성을 선택하세요」 오류가 났다면 1. 앱 구성에서 만든 구성을 선택하지 않은 경우입니다.

다른 사람 댓글에도 바로 DM이 가나요?

네, 됐습니다. 2026년 11월 25일 소통마케팅센터 앱은 아직 개발 모드였지만, 앱에 아무 역할이 없는 외부 계정 1곳이 릴스에 단 댓글이 들어왔고 약 1분 만에 DM이 나갔습니다. DM 속 버튼을 누른 신호도 들어왔습니다. 다만 외부 계정 1곳으로 확인한 결과라, 여러 계정에서 막히면 그때 메타 앱 검수를 신청하면 됩니다.

정리

인스타 댓글 자동 DM은 메타 앱 6단계만 정확히 밟으면 연결됩니다. 콘텐츠 관리 필터, Instagram 테스터, 광고 권한 빼기 세 곳만 조심하고, 토큰은 바로 복사, 웹훅 저장 뒤 comments 구독까지 켜 두세요. 제천·단양·영월 사장님 가운데 직접 연결이 어려우시면 소통마케팅센터로 문의해 주세요.
